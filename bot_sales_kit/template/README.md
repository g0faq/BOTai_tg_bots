# Telegram-бот репетитора

MVP бота для ежедневной работы репетитора: ученики, расписание, стабильные занятия,
закрытые слоты, отмены без штрафов, домашние задания, чеки, подтверждение оплат,
баланс занятий, должники, планы подготовки и статистика тем.

## Что уже заложено

- анкета и карточка ученика;
- роли `admin`, `student`, `parent`;
- расписание, разовые занятия и стабильное расписание до даты;
- проверка конфликтов с занятиями, закрытыми слотами и рабочими часами;
- отмена занятий без списания оплаты;
- списание оплаты только после статуса `проведено`;
- два режима баланса: занятия и деньги;
- история оплат, чеки со статусом ожидания и подтверждения;
- домашние задания и отправка решений;
- индивидуальный план, план подготовки текстом/картинкой и статистика подготовки;
- уровень знания по каждому заданию ОГЭ/ЕГЭ по шкале от 0 до 10;
- кнопочная запись: длительность, две ближайшие недели и свободное время;
- Telegram Mini App: личный кабинет ученика и админ-панель в веб-интерфейсе;
- анкета спрашивает роль: ученик или родитель;
- предметы и виды подготовки выбираются кнопками;
- стоимость не спрашивается у ученика, админ задает цены за 60, 90 и 120 минут;
- админское расписание открывает занятия кнопками;
- запись и расписание показывают текущую неделю и кнопку перехода на следующую;
- ученик хранит свой часовой пояс: запись показывает его локальное время, а админ видит МСК;
- админ может закрывать свободные окна и целые дни на любую будущую дату командами;
- тесты критичной бизнес-логики.

## Быстрый запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env` нужно заполнить:

- `BOT_TOKEN` — токен от BotFather;
- `ADMIN_TELEGRAM_IDS` — твой Telegram ID, можно несколько через запятую;
- `TEACHER_CHAT_URL` — публичная ссылка на чат с тобой, например `https://t.me/username`.
  Если оставить пустым, бот использует первого админа как `tg://user?id=...`;
- правила работы: часы, цена, длительность, размер пакета.
- `WEBAPP_URL` — публичный HTTPS-адрес Mini App. Для локальной проверки можно оставить
  `http://127.0.0.1:8000`, но в Telegram на телефоне нужен публичный HTTPS-домен;
- `GOOGLE_SHEETS_SPREADSHEET_ID` — ID Google-таблицы для статистики проведенных уроков;
- `GOOGLE_SHEETS_CREDENTIALS_FILE` — путь к JSON-ключу service account.
  Вместо файла можно заполнить `GOOGLE_SHEETS_CREDENTIALS_JSON` целым JSON в одну строку.
  Таблицу нужно открыть для email service account на редактирование.
- `PAYMENT_DETAILS_TEXT` — текст с реквизитами оплаты, который бот отправляет ученику
  после занятия, если баланс закончился.

Основное управление в Telegram сделано через кнопки:

- `Ученики` — карточки учеников, цена, ссылки, ДЗ и удаление;
- `Расписание` — 7 ближайших дней отдельными сообщениями;
- `Ожидают оплаты` — подтверждение или отклонение чеков;
- `Должники` — быстрый список тех, кому нужно напомнить об оплате.

Закрыть окно для записи можно командой:

```bash
/close 20.11 15:00 17:00 личные дела
/close_day 20.11 личные дела
```

Если нужна конкретная дата далеко вперед, можно указать год: `20.11.2026`.

Разовое занятие ученику можно добавить из карточки ученика кнопкой `Добавить разовое`:
бот последовательно предложит длительность, дату и свободное время. Ученику придет
сообщение без внутренних номеров `#`.

Часовой пояс ученика задается в анкете и редактируется в карточке. Можно писать
IANA-зону (`Asia/Yekaterinburg`, `Asia/Novosibirsk`) или коротко: `мск`, `екб`,
`нск`. Рабочие часы и конфликты считаются по часовому поясу преподавателя из
`TIMEZONE`, по умолчанию `Europe/Moscow`.

Стабильное расписание добавляется кнопками через `Регулярное расписание` или
`/regular`: сначала выбирается день недели, потом время. За один проход добавляется
один стабильный урок, например понедельник 18:00. Если у ученика указана дата
экзамена, занятия создаются до нее; если даты экзамена нет, бот создает занятия
на год вперед.

Очистить будущие стабильные занятия можно кнопкой `Очистить стабильное` в карточке
ученика или командой `/clear_regular ID_ученика` для админа. Ученик очищает свое
стабильное расписание кнопкой `Очистить стабильное расписание`.

Прогресс по заданиям ОГЭ/ЕГЭ задается командой:

```text
/task_progress ID_ученика номер_задания уровень_0_10
/task_progress 1 13 7
```

План подготовки можно сохранить текстом:

```text
/prep_plan 1 Июнь: задания 1-7, июль: пробники раз в неделю
```

Или картинкой: отправь изображение с подписью `/prep_plan 1`.

Запуск:

```bash
./run_bot.sh
```

Запуск Mini App:

```bash
./run_webapp.sh
```

Локальная проверка Mini App доступна на `http://127.0.0.1:8000`. Если страница
открыта не из Telegram, она попросит Telegram ID пользователя из таблицы
`user_accounts`. Также можно открыть сразу с параметром `?dev_id=TELEGRAM_ID`.

Чтобы кнопки Mini App появились в меню Telegram, укажи `WEBAPP_URL` в `.env` и
перезапусти бота. Для реального Mini App адрес должен быть HTTPS и доступен
из интернета.

Проверка ядра без Telegram:

```bash
python3 -m unittest discover -s tests
```

Проверка перед запуском:

```bash
python3 -m compileall -q src tests
python3 -m unittest discover -s tests
```

## Google Sheets

Когда урок помечается командой `/conducted`, бот обновляет Google-таблицу:

- лист `Уроки` — все проведенные уроки, дата, ученик, длительность, рабочие часы и стоимость;
- лист `Статистика` — итоги по зарплате, количеству уроков и рабочим часам, а также сводки по месяцам и ученикам.

Для ручной полной синхронизации старых проведенных уроков есть команда `/sync_sheets`.

## Минимальный чек-лист запуска

1. В `.env` заполнить реальный `BOT_TOKEN` и `ADMIN_TELEGRAM_IDS`.
2. Запустить `python3 -m tutor_bot.main`.
3. Написать боту `/start` с админского аккаунта и убедиться, что открылась админ-панель.
4. Заполнить тестовую анкету с ученического аккаунта.
5. В админке открыть `Ученики`, задать цены и ссылки.
6. Проверить `Записаться`, `Расписание`, `Выдать ДЗ`, `Отправить чек`, `Ожидают оплаты`.

## Что нужно от владельца бота

1. Создать бота в BotFather и вставить токен в `.env`.
2. Узнать свой Telegram ID и вставить в `ADMIN_TELEGRAM_IDS`.
3. Решить базовые правила: рабочие дни, рабочие часы, стандартную длительность,
   цену занятия и размер пакета оплаты.
4. Для каждого ученика подготовить ссылки на Яндекс Телемост и онлайн-доску.

## Архитектура

- `src/tutor_bot/domain` — сущности, статусы и бизнес-типы.
- `src/tutor_bot/services` — правила расписания, оплат, ДЗ и подготовки.
- `src/tutor_bot/storage` — SQLite-хранилище без внешних ORM-зависимостей.
- `src/tutor_bot/bot` — Telegram-обработчики и клавиатуры.
- `src/tutor_bot/webapp.py` и `src/tutor_bot/web/static` — API и интерфейс Mini App.
- `tests` — тесты ядра, которые не требуют токена и Telegram.
